# 🛰️ Segmentation d'Images Satellites (Histogramme & Contours Actifs)

## 📝 Présentation
Ce projet est une implémentation et une amélioration des techniques de segmentation d'images satellites présentées dans l'article scientifique *"Satellite Images Segmentation Based on Histogram and Active Contour Algorithm"*.

L'objectif est de diviser une image satellite en régions homogènes en utilisant :
1. L'analyse des histogrammes d'intensité.
2. Les contours actifs (Active Contours / Snakes).
3. La détection de bords (Canny, LoG, Roberts).

## 🎯 Objectifs
*   Comprendre et résumer l'approche de l'article.
*   Implémenter la méthode en Python (OpenCV, NumPy, Matplotlib).
*   **Proposer des améliorations** (Seuillage d'Otsu, K-means, Watershed) et comparer les résultats.

## 🛠️ Technologies Utilisées
*   **Langage :** Python 3
*   **Bibliothèques :** OpenCV, NumPy, Matplotlib, Scikit-image
*   **Environnement :** Jupyter Notebook / Scripts Python
